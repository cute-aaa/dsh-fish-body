# 内置分层皮肤：来源与授权

本目录随 npm 包发布，是 `layered` 渲染的开箱素材（清单见 `assets/core-skins.json`）。

## 内容

| 目录        | 层数 | 与另一套的差别                       |
| ----------- | ---- | ------------------------------------ |
| `feiyu-05`  | 18   | 头饰 `09_headwear.png` 为不锈钢盆     |
| `feiyu-muyu`| 18   | 头饰换为木鱼；点击音效换了一份         |

其余图层（后发 / 衣服 / 脸 / 五官 / 前发）两套逐字节相同，`manifest.json` 与 `persona.md` 也相同。

## 来源

- 这两套由仓库作者（`cute-aaa`）制作并自用，随本次开源改造从作者本机的
  `<数据根>/skin/layered/` 迁入包内，**不是**第三方素材站下载物。
- `manifest.json` 里的 `author` 字段是皮肤编辑器写入的占位值（`you`），不代表第三方作者。
- `persona.md` 标注「占位，可整段重写」：它只是让分层皮肤在首次加载时不至于没有人设。

若你确信其中某张图来自你的作品，请开 issue，我们会在下一个版本移除或补上署名，**不需要你提供额外证明**。

## 用户覆盖

放进 `<数据根>/skin/layered/<同名 id>/` 即可整体覆盖内置那份（宿主按「用户皮肤根 → 池 → 包内只读池」
的顺序查找，见 `src/host/pool/resolve.ts` 的 `appendPackagePoolRoot`）。内置皮肤不是运行必需项：
删掉包内目录只是让右键「皮肤」菜单少两项。
