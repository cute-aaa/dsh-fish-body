# 图集素材来源与授权

本目录混了两类内容，授权不同，分别说明。

## 1. 通知头像 `notify-*.png`（7 张）

- 内容：「大肥鱼」形象的 Q 版立绘，用于任务完成 / 报错 / 提问 / 截断等系统通知的头像。
- 授权：随形象授权，**CC BY-NC-SA 4.0**（署名 · 非商业 · 相同方式共享）。**禁止商用。**
- 来源链：随源仓库 `dsh-pet` 迁入；与 `assets/main-character.png` 同一形象体系，出处见仓库根 `NOTICE` 第 2 节。

## 2. 拖拽光标 `cursor-grab.png` / `cursor-grabbing.png`（2 张，实为 WebP，32×32）

- 内容：通用「抓取 / 抓取中」手形光标。
- 来源：**未记录**（早期引入时未留来源）。形态与常见开源光标集一致，但无法确认具体出处。
- 处置建议：公开发布前替换为许可明确的实现——要么自绘，要么取自 MIT / CC0 光标集（如 Lucide、Tabler、Open Cursor Library），并在本文件更新来源。替换前按「来源不明」对待。
- 争议处理：若你是这两个光标的作者，请开 issue，我们会在下一个版本移除或替换。

## 3. 其余

- 本目录不含字体、不含 Live2D 运行时；那两类见仓库根 `NOTICE` 第 4、5 节。
