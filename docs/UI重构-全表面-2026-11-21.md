# UI 重构计划 · 全表面统一（2026-11-21）

> 对象：`dsh-pet/src/client/**` 的六个 UI 表面——设置页、对话面板、会话鱼浮层、宠物本体（含右键菜单/提示）、运行时缺失弹窗、设置页预览。
> 依据：`apple-design`（流体交互、弹簧、中断性、材质、排版光学）与 `frontend-polish`（克制、结构先于装饰、反 AI 模板）两个 skill 的口径。
> **硬约束：功能零变化**。不改 IPC 频道、不改状态真源（`windows.js` 现算原则）、不改 openapi/路由/schema、不改物理行为的模式集合（sling/throw/place 三去向不变）、8 份 locale 字典键集保持一致。

## 一、一句话方向

设置页 2026-11-14 那轮已经建立了 `--pcg-*` 尺度纪律；本轮把这套纪律**推广到其余五个表面**，并补齐宠物物理的 Apple 手感三短板（速度衔接、动量语义、边界反馈），同时把三份各自为政的提示层收敛为一个共享实现——**动效同语言、提示同实现、物理同口径**。

## 三、目标规格（先定尺，后动手）

### 3.1 动效 token（新增 `shared/motion.ts`，各表面注入同名 CSS 变量）

| token | 值 | 用途 |
| ----- | -- | ---- |
| `--pet-dur-fast` | `120ms` | 状态反馈（hover、开关、chip） |
| `--pet-dur` | `160ms` | 位移 / 展开 / 入场 |
| `--pet-dur-slow` | `240ms` | 弹窗类大表面 |
| `--pet-ease` | `cubic-bezier(.2,.7,.3,1)` | 全部过渡共用（设置页现值，全仓唯一缓动） |
| `--pet-press` | `scale(.98)` / `80ms` | 按下反馈，全表面统一手感 |
| `--pet-focus-ring` | `box-shadow:0 0 0 2px var(--dsw-focus-ring-color,…)` | 焦点环，替换 TS 常量拼串 |

颜色仍一律 `--dsw-*`；**动效**收敛为本插件自有 token（宿主 `--ds-*` 若变节奏，插件手感不受牵连）。会话鱼与设置页字号用 `--pcg-fs-*` 同一档（11/12/13/14）。

### 3.2 交互物理（apple-design §3/§5/§6/§9）

- **中断性**：飞行/走位中 `pointerdown` 必须从**当前呈现值**（live box）接管——实现已按此设计，补守卫测试锁死。
- **速度衔接**：松手初速已由 trail 估算传入飞行——补「飞行首帧速度 = 松手速度」的回归断言。
- **边界橡皮筋**：拖拽超出视口时按 `overshoot·dim·c/(dim+c·|overshoot|)`（c≈0.55）渐进阻力，替换硬夹紧；只在**拖拽**阶段生效，飞行物理的反弹（`RESTITUTION`/`PET_BOUNCE_E`）不动。实现在 `shared/physics/spring.ts` 旁新增纯函数 + 单测，浏览器半侧与桌面 Helper 同源。
- **落点语义**：宠物是自由飞行体（重力+反弹），**不引入** Apple 的 snap 投影——那是翻页/抽屉的模型；仅保留现有挤压落地。

### 3.3 提示层统一

一个 `shared/tooltip.ts` 出口，三处只留「参数差异」：

| 表面 | 定位 | 字号 | 触发 |
| ---- | ---- | ---- | ---- |
| 宠物页/桌面 | `tooltipPlacement`（现有） | `--dsh-pet-font-tip`（随宠物尺寸，保留） | 悬浮 |
| 设置页 | 同一 `tooltipPlacement` | `--pcg-fs-label` | `data-tip` 委托（契约不变） |
| 对话面板 | 同一 `tooltipPlacement` | `--dsw-font-xxs-12` | 现有触发点不变 |

入/出对称：只动 opacity，进出同 120ms（apple-design §7 空间一致）；不新增动画形式。

### 3.4 无障碍三信号全覆盖（apple-design §14）

- `prefers-reduced-motion: reduce`——六个表面全有（对话面板**新增**：过渡压 1ms；转圈保留但允许静态替代：进度语义的 spinner 归「状态反馈」，保留转动、去掉无关过渡）。
- `prefers-reduced-transparency: reduce`——**新增**：runtime-prompt 遮罩去 blur 提高底色不透明度；其余表面无半透明材质，不造。
- `prefers-contrast: more`——**新增**：设置页卡片与对话气泡补 `1px` 实线高对比描边档。
