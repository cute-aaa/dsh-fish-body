## 二、本轮完成的三件事

### ✅ 任务 1：桌面独立窗口（form=desktop 仍显示在浏览器内）

- `lib/index.js` 新增 `syncDesktop()`：`onConfigMutated()`、5s 定时器、启动时（`followDsh`）统一走它；`form` 从非 desktop → desktop 开窗，反向关窗，禁用插件时按 `followDsh` 收窗。
- `client.js` 的 `FishBodyPet` 先读 `state.form`，`desktop` 形态直接不挂载；`core.js` 也兜了一层（浏览器半区遇到 `form=desktop` 隐藏并暂停视频/rig），所以「重启/应用」两个按钮都能把两个形态切干净。
- `lib/desktop.js` 重写：`resolveElectron()` / `resolveChromium()` / `windowSizeFor()` / `launchStandalone()` / `stopStandalone()` / `status()`；子进程句柄模块级保存，窗口被用户关掉时自动清空状态；重复开窗返回 `reused: true`；关闭用 `taskkill /T /F` 杀整棵进程树。
- 新增 `GET/POST /api/fish-body/desktop`（状态 / 手动开关），设置页有「打开桌面窗口 / 关闭 / 刷新状态」和当前引擎提示。
- `assets/standalone.html`：非 Electron（普通 app 窗口不能透明）时给深色底，Electron 下保持透明。

### ✅ 任务 2：动画「动画→常态→动画」丝滑过渡

- `assets/core.js` 改为**交叉淡入淡出**：动作播放时 `idle` 淡出到 0（不再留在底下透出来），动作 `ended` 后 `idle` 淡回 1、动作层再 `display:none`；淡入淡出 140ms。
- 首帧就绪才显示（`loadeddata` / `readyState>=2` 复用），并加了 `warmAction()` 预热点击动画，第一次点击不黑闪。
- 动作之间互不影响：每次点击都是独立 token，`ended` / 新动作 / 卸载都会让旧 token 失效。
- 实测（`tools/cdp-shot.mjs`）：点击后动作层 `block/1`、idle `0`；10s 动作播完变成 `none/0` + idle `1`。

### ✅ 任务 3：layered-PNG 渲染器（surfcore 皮肤格式）

- 新增 `assets/layered.js`（纯 canvas 2D，零依赖）：
  - 按 `manifest.layers` 顺序合成 18 层 PNG；图层位图用 `createImageBitmap` 预缩放到 0.6（1280 → 768），显存/采样成本减半；
  - 只渲染 `hitbox`（+3% 余量）区域并按容器等比缩放，所以 1280² 的皮肤在 200~400px 的框里是满幅；
  - 呼吸/摇摆/果冻/拖动挤压/跳（body）、转头+倾斜（head）、视线（iris 位移）、眨眼（眼白/虹膜淡出 + 睫毛下移）、张嘴（`mouth.open` + `openCover`，说话时随音节开合）、摸摸闭眼、hover 闭眼；
  - 命中区：`interaction.regions` 的 `ellipse`/`rect`，`pokeAt()` 按 region 的 `gesture`（pat/poke/hop）播动作并播 `interaction.sounds`（`pot-hit`）；`clientPoint()`/`toCanvas()` 做屏幕↔画布换算。
- `assets/core.js` 增加 `modelType: 'layered'` 分支：动态加载 `layered.js`、拉 `manifest.json`、挂 canvas；失败退避 30s 后重试并显示 🖼️ 占位。
- `lib/assets.js`：扫描 `manifest.json` 且 `rig: "layered"` 的目录，`assets.manifest.skins` 带 `{id,name,path,canvas,layerCount,preview}`。
- `lib/routes.js`：`/fish-body-assets/skins/<id>/<rel>`（防穿越），`GET /api/fish-body/skins`、`GET /api/fish-body/skins/<id>`。
- `lib/config.js`：`modelType` 增加 `layered`，新增 `layeredSkin`（默认 `feiyu-05`）。
- `client.js` 设置页：「动画类型」增加 `layered`，新增「分层皮肤」下拉（从 `/api/fish-body/assets` 的 `skins` 生成）。

## 四、已知事项 / 下一步

1. **宿主代码改动需要重启 dsh**：`lib/*`（含路由、配置 schema）改了必须重启 fish profile；`assets/*.js` 是 `no-store` 静态文件，改完刷新页面即可。HMR 在当前 profile 报 `restart-required: module-comparison`，不能热替换。
   - 重启：`powershell -NoProfile -ExecutionPolicy Bypass -File D:\NodeJS\DSH\start-fish.ps1`（先 `Stop-Process -Id <pid>` 掉旧的，端口 3099）。
2. **fish profile 当前配置**：`form: desktop`、`size: 400`、`modelType: layered`、`layeredSkin: feiyu-05`（本轮已从 `live2d` 占位改成能直接看的 layered 皮肤）。重启后 `followDsh: true` 会自动开一个桌面窗口（本机没有 Electron，所以是 Edge 应用窗口）。
3. **`size` 配置这轮才真正生效**：桌宠框宽 = `size × scale`（之前 `size` 只写进状态、渲染没读），所以 400 会比以前看起来大。
4. **新旧宿主兼容**：浏览器半区只在状态里**有 `desktop` 字段**（= 新宿主）时才按 `form=desktop` 隐藏自己；旧宿主没有该字段时保持旧行为，避免升级途中桌宠突然消失。
5. **没有 Electron**：`resolveElectron()` 找不到（`%LOCALAPPDATA%\Programs\dsh-pet-electron\electron.exe` 不存在、`DSH_ELECTRON_PATH` 也没设），所以桌面窗口实际走 Edge 的 `--app=`；想用真正透明无边框窗口，装 Electron 并设 `DSH_ELECTRON_PATH`。
6. **live2d 仍是占位**：没有 `.moc3` 模型，需要自带模型 + pixi/Cubism SDK。
7. **layered 皮肤可以继续打磨**：
   - `interaction.regions` 是按顺序命中的，`pot`（cy 425 / ry 160）会盖住 `head` 圆的下半部分，所以点头部中间命中的是 pot；要分开得改皮肤 manifest 的 `cy/ry`。
   - 皮肤 `persona.prompt`（`persona.md`）还没接进 `chat`，可以像人格卡一样喂给 LLM。
   - 皮肤音效目前只支持 `interaction.sounds` 的点击音；「待机循环音效」仍走 `webmIdleSound`（layered 下不播）。
8. **`test-smoke.mjs`** 不在 `files` 白名单，仅开发用；`tools/` 同理。
9. 动画资源：118 个 webm（59MB）、12 个音效、`pot-hit.wav`、layered 皮肤 1 套。
