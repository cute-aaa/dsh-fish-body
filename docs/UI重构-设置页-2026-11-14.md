# 设置页 UI 重构（2026-11-14）

> 对象：DSH 插件设置页「桌宠配置」（`settings.section` / `pet-config`，源码 `dsh-pet/src/client/settings/**`）。
> 非目标：`src/standalone/settings-page/**`（独立模式那套脚本页）、桌宠渲染、对话面板、host 半侧、配置 schema 与路由。
> 本文记录这一轮的决定与依据，便于下一轮接手时知道「为什么长这样」，也便于回滚。

## 一、一句话方向

从「七个分区、四十个问号、三排选中条、四个底部按钮」收敛成 **6 个分区、一套控件规格、卡片内分小节、一个保存栏**：
层级靠留白与字重，不靠边框、问号与常显小字；常用项前置，维护动作沉底。

## 二、信息架构

| # | id | 标签 | 内容 |
|---|----|------|------|
| 1 | `pet` | 桌宠 | 种类下拉 + 实例 chip + 单卡（身份 / 显示与位置 / 功能 / 人设折叠） |
| 2 | `feel` | 外观与手感 | 物理（含移动端折叠）/ 动作频率 / 字体 |
| 3 | `audio` | 声音 | 音效总闸 → 事件音效（明细折叠）→ 自定义 hook → 语音播报（本地接入折叠） |
| 4 | `chat` | 对话 | 模型 / 上下文 / 三个开关 / token 成本折叠 |
| 5 | `fish` | 会话鱼 | 启用与预览 → 皮肤与尺寸 → 播报 → 节奏 |
| 6 | `system` | 系统 | 提醒与桌面 / 备份与恢复 / 快捷键 / 高级配置 / 存储卸载 / 插件维护 |

- 原 `behavior` + `look` 合并为 `feel`：「外观」只有一张字体卡，一个分区换一次点击不值。
- 旧的 `localStorage` 分区记忆按 `parseTabId` 校验，`look` / `behavior` 自动回落默认 `pet`，不需要迁移。
- 页面级 `<h2>桌宠配置</h2>` 删除：设置页左侧导航已经显示同一个名字。

## 三、删掉的东西（以及为什么）

| 删除 | 原因 | 替代 |
| --- | --- | --- |
| 字段 / 开关旁的约 40 个 `?` | 每个控件一个问号把视线切碎，信息大多能从标签读出来 | 字段说明挂 `data-tip` + 卡头保留 1 个 `?`；真会踩坑的写成常显 `note` |
| 字段级「未保存」圆点（约 20 个） | 同一条信号在标签、卡头、分区上重复三遍 | 只保留卡头 + 分区标签上的圆点，底部栏给未保存条数 |
| 底部栏「重启」 | 一年点两次的维护动作占着最显眼的按钮位 | 迁入「系统 → 插件维护」 |
| 每个分区底部重复渲染的「重置」行 | 六个分区各出现一次 | 迁入「系统 → 插件维护」，全页只一处 |
| 音效卡 8 个「打开文件夹」与 8 条常显命名规则 | 一面墙，且八个按钮同名 | 卡头 1 个「打开文件夹」+ 「来源、路径与命名规则」折叠 |
| `sfx-card` 自带的浮层实现（`FolderTip` / `tooltipPlacement` / `__sfxTip*`） | 与 `folder-button.ts` 重复 | 统一复用 `folder-button.ts` |
| 动作频率卡里只读的「随机动作」输入框 | 看着能改、其实改不了的假控件 | 纯文本读数 |
| `<h2>` 标题、「种类」「宠物列表」两个行内标签 | 与导航 / 选择器自身层级重复 | 删除 |

## 四、加上去的东西

1. **撤销改动**：底部栏在 `busy` 之外多一个「没有改动就禁用」的按钮。实现是重新拉配置与会话鱼（复用加载链路），
   而不是本地回滚快照——快照回滚要维护第二份「路径 → 控件状态」的映射，重读天然与基线一致。
2. **未保存条数**：底部栏左侧只有一条状态（有保存结论就显示结论，否则显示「未保存 n 项」）。
3. **卡片内小节**：`section()` 提供第二层分组（只有相邻小节之间画 1px 分隔线），避免整页变成卡片汤。
4. **折叠**：移动端效果、每种渲染方式的大小、音效来源与命名、token 成本说明、人设——默认收起，展开即全量信息。
5. **来源徽标**：音效槽位的来源（内置默认 / 皮肤 / 未匹配…）缩成一枚小徽标，未匹配带告警色。

## 五、视觉与交互规格

- 尺度：间距 4 / 8 / 12 / 16；控件 28px 高、圆角 8px；卡片圆角 12、内边距 14×16。
- 字号：标题 14/500、正文 13、标签 12、元信息 11；标题 `letter-spacing: -0.01em`。
- 颜色：全部取 `--dsw-*`（`settings-card-fill/stroke`、`state-business-primary`、`switch-thumb`、`button-info-fill`…），
  缺 token 时按 `var(--dsw-x, fallback)` 回落；没有字面色值（主题色与深色模式由宿主决定）。
- 开关：34×20 轨道 + 16 thumb，视觉是开关、语义仍是 `checkbox`（这些开关随「保存」整包落盘，不是即时生效）。
- 分段标签：一条轨道 + 选中块（`button-ghost-active-fill` + 内描边），等宽；窄容器（≤400）折成两行而不是横向滚动。
- 动效：分区内容入场 160ms（透明度 + 6px 位移）、折叠 `grid-template-rows` 160ms、开关 120ms、按钮按下 0.98/80ms；
  `prefers-reduced-motion: reduce` 把动画与过渡压到 1ms。
- 响应式：容器查询 600px（四列降两列）与 400px（全部单列、头像回到 72px 方块、底部栏按钮平分）。

## 六、保存语义（未改）

`应用` / `确定` 仍然整包写主配置并以独立文件写会话鱼；即使没有改动也会写（不做「干净就跳过」的优化，
否则会出现「文件缺字段但页面看着干净所以没写」的边角）。控制台快捷键 `Ctrl+S / Cmd+S` 仍等于「应用」。

## 七、验证

- 单元：`npm test`（3189 条，新增 `sfx-slot-row` / `sfx-hooks` / 维护卡用例；`ui` / `bar` / `tabs` / `dirty` / `css` 契约按新结构重写）。
- 浏览器：`npm run test:ui`（Playwright，真实 React + Chromium，360/520/900 × zh/en，含截图模式
  `DSH_PET_UI_ARTIFACTS=<dir>`；截图时用 `animations: 'disabled'` 把入场动画快进到终态）。
- 门禁：`typecheck`、`lint`、`format:check`、`check:cycles` 全绿。
- 未做：真实 DSH 页面肉眼验收（需要把 `DSH_HOME/plugins/dsh-fish-body` 的 junction 临时指向本工作区并重启 profile）。
  主题 token 由宿主注入，插件只按 token 取名，因此这一步只验观感不验功能。
