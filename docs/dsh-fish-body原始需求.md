## 一、项目背景

当前 dsh 的 fish profile 下的 `dsh-fish-soul` 插件定义了"大肥鱼"的人格。请开发一个**桌宠 dsh 插件**，用于接入该 soul 人格，即**原生使用人设卡**，而不是同步或解析人设卡。

## 二、开发与运行环境

- 基于 **deepseek-harness** 进行开发，插件最终**运行在 dsh 上**。
- 技术选型请**结合性能、资源占用与功能需求挑选最优方案**，并简要说明选型理由。
- 可以参考主流项目实现（已 clone 到 `G:\Projnew\git\dsh-body`）。

## 三、交付物

- 交付本提示词"四～七"所列**全部功能的完整代码**，不要省略实现。
- 前提约束：**在实现全部功能的基础上，性能和资源占用越优越好**。
- 插件开发完成后，参考目录（ `G:\Projnew\git\dsh-body`）下项目中包含的 live2d/webm 等资源应当能直接使用，如果不能则说明原因。

## 四、功能需求

**1. 环境识别**

- 能识别 dsh 目录配置和 profile，例如用户设置的 `DSH_HOME` 环境变量、当前 profile 等。

**2. 人格接入接口与实现**

- 定义接入接口和实现，支持接入常见的"dsh 人格"项目，例如 `dsh-fish-soul`、`dsh-soul`、`dsh-rofm`、`dsh-suzu-memory` 等。
- 接口支持自行扩展实现类。
- 明确说明：此处的"接入"是指**原生使用人设卡**，而不是同步或解析。

**3. 动画资源支持**

- 支持 live2d、webm。
- 每个 UI 的**点击动画、点击音效、动画音效**都可以自定义。

**4. 资源扩展**

- 支持后期添加和修改动画、音效等（例如将其他开源项目中的动画/音效拿来导入和使用）。

**5. 语音接入**

- 支持接入语音（GPT-SoVITS、TTS、云端语音等）来使用语音回复。

## 五、互动能力

互动基于人设进行，需支持：

- 根据人设进行发言互动；
- 可开启**实时显示 dsh 任务状态**；
- 可开启**识别用户当前屏幕内容并互动**。

## 六、设置项

- **随 dsh 启动 / 随 dsh 停止**；
- 集成形态：**"集成到浏览器 dsh 页面内"与"桌面独立窗口"两种都完整实现**，由用户在设置中切换。

## 七、避让场景（多选式）

用户可多选启用以下避让行为：

- 全屏时避让；
- dsh 不对话时避让；
- 随 dsh 启停；
- 应用名单避让（指定一些应用在前台时避让）。

## 八、非功能性要求

- 资源占用小，性能高；
- 每个功能分模块开发，便于扩展；
- 在实现功能的前提下，性能和占用越优越好。
