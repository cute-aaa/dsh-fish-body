# 目录布局（2026-11-14 起）

> 权威树 + 迁移表 + 「为什么长这样」。设置页「系统 → 文件与目录」显示的就是这棵树（宿主生成，见
> `dsh-pet/src/host/user-layout.ts`），两者不一致时以代码与本文件为准。

## 一、一句话

所有落到这台机器上的东西，都在这一个数据根里：`<DSH_HOME>/fish-body/`。
删掉它 = 除插件本体外全清；删掉其中的 `cache/` = 什么都不影响。

## 二、树

```
<DSH_HOME>/fish-body/
├─ config/                     设置（用户的东西，删了等于重置）
│  ├─ main-config.jsonc        主配置：JSONC 带注释；设置页「同步」写的就是它
│  ├─ session-fish.json        会话鱼设置（独立文件，整份重写不碰主配置的注释）
│  └─ voice-providers.json     本地语音接入（服务地址 / 音色 / 素材目录）
├─ data/                       数据（用户的东西）
│  ├─ memory.json              对话记忆（按宠物分桶）
│  └─ todos.json               待办清单
├─ runtime/                    运行时（不属于缓存：删了要重新下载）
│  └─ electron/                Electron 运行时（约 350 MB，桌面窗口用；设置页可点「下载运行时」）
├─ cache/                      唯一允许随手删的目录（删了自动重建或重下）
│  ├─ voice/                   语音合成缓存（命中即免合成）
│  ├─ download/                Electron 安装包下载缓存（@electron/get 的 cacheRoot）
│  └─ desktop/                 桌面窗口的 Chromium profile（窗口状态 / 会话鱼位置记忆）
├─ pets/                       文件宠物：一种一套
│  ├─ pig-config.json          <名>-config.json 定义一种「种类」
│  ├─ pig-animation/{webm,mov} 同一前缀的动画目录
│  ├─ pig-sound/               同一前缀的音效目录（可选）
│  └─ pig-memes/               同一前缀的表情包目录（可选）
├─ assets/                     素材（所有宠物共用）
│  ├─ animation/{webm,mov}     main 的动画（文件名即动作名）
│  ├─ sound/                   用户级音效：无前缀的 click.wav 对所有宠物生效
│  ├─ memes/                   用户级表情包图片
│  ├─ skin/                    共享皮肤池（池根，= assets.pool 的默认值）
│  │  ├─ layered/              layered 皮肤：一个子目录一套（manifest.json 优先）
│  │  ├─ live2d/               live2d 模型目录
│  │  ├─ webm/                 平铺的 webm 动画
│  │  └─ sound/                池的全局音效
│  └─ session-fish/            会话鱼皮肤（图片 / 动图 / 视频）
└─ logs.txt                    统一日志（1 MB 上限，写满留最新 512 KB）
```

设置页里每个目录在 Windows 资源管理器都带一句备注（`desktop.ini` 的 `InfoTip`），
所以不必回来查这张表也能知道「这个目录是干什么的、能不能删」。

## 三、四类目录的删法

| 目录 | 删了会怎样 | 该不该删 |
| --- | --- | --- |
| `config/` `data/` | 丢设置、丢对话记忆与待办 | 只在「我要重置」时删；想保留先备份 `config/main-config.jsonc` |
| `runtime/` | 桌面模式要重新下载 Electron（设置页可点「下载运行时」，或下次开桌面窗口自动下） | 只有换机器 / 清理磁盘时 |
| `cache/` | 语音重新合成、安装包重新下载、桌面窗口状态重置 | 随时，删了不影响设置与运行 |
| `pets/` `assets/` | 素材没了（宠物本身还在，只是没东西可放） | 按需要 |

## 四、从 dsh-pet 布局迁移

历史原因：本插件最早从上游 `dsh-pet` fork，数据根与目录名都沿用了它的。两者装在一起就是同一个
`<DSH_HOME>/dsh-pet/`，配置互相覆盖、素材串台，所以这轮整体换根 + 分组。

启动时自动完成（`host/user-root.ts` + `host/migrate-layout.ts`），规则：

| 旧 | 新 |
| --- | --- |
| `$DSH_HOME/dsh-pet/`（整根） | `$DSH_HOME/fish-body/`（同盘 rename；跨盘/占用则复制并保留旧根） |
| `main-config.jsonc` `main-config.json` `session-fish.json` `voice-providers.json` | `config/`（文件名不变） |
| `memory.json` `todos.json` | `data/` |
| `main-animation/` | `assets/animation/` |
| `main-sound/` | `assets/sound/` |
| `memes/` | `assets/memes/` |
| `skin/` | `assets/skin/` |
| `session-fish-skin/` | `assets/session-fish/` |
| `pet/` | `pets/`（pack 内命名与配对规则不变） |
| `voice-cache/` | `cache/voice/` |
| `$DSH_HOME/electron/` | `runtime/electron/` |
| `%APPDATA%/dsh-pet-electron-helper/` | `cache/desktop/`（Electron `userData`） |
| `%LOCALAPPDATA%/electron/Cache/` | `cache/download/`（只改 cacheRoot，旧目录不搬） |

- **绝不覆盖、绝不删除源**：目标已存在就跳过并告警；单个条目失败不影响其它条目，下次启动会接着搬。
- **两个根并存**（例如桌面 Helper 先把新根建出来，数据还在旧根里）：按「同名分组」把 `config/`、`data/`、
  `pets/`、`assets/`、`cache/voice/`、`runtime/electron/`、`logs.txt` 整组搬进新根，再按上面的平铺表兜底。
  所以旧根整理过没整理过都能搬。
- 回执写在 `<数据根>/.layout.json`；`node scripts/migrate-layout.mjs`（默认干跑）可以预览，
  `--apply` 手动搬，`--revert` 按回执搬回。
- 换名失败（跨盘 / 被占用）时先复制；复制也失败就**继续在旧根上工作**——根名难看，但一个字节的配置都不会丢。

## 五、为什么不在插件包目录里

`<DSH_HOME>/plugins/dsh-fish-body`（或 profile 的 `node_modules/dsh-fish-body`）是**代码**，
由 DSH 安装、升级、卸载；把用户数据写进去，升级一次就没了。所以「插件目录」= 数据根，不是包目录。

想整体搬走（换盘、放进同步盘）：把 `fish-body/` 整个目录挪过去，然后用 `DSH_HOME` 指到新位置即可，
内部全是相对路径，没有写死的绝对路径。
