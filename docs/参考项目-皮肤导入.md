## 二、各项目盘点

### 1. `dsh-pet`（= 本 fork 上游，webm 权威）
- `dsh-pet/assets/webm/`：114 个 VP9-alpha webm，与 `dsh-pet/assets/config.jsonc` 的动画池一一对应。
- 本项目 `dsh-fish-body` 就是它的 fork，主宠物已用同一批素材。**无需再导入**，仅作为 webm 契约与动作映射的对照源。

### 2. `dsh-pet-indesktop`（shenshen 第二包来源）
- `assets/characters/shenshen/videos/{idle,turn,drag,click,move,random,events/balance}`：106 webm，按类别分目录。
- `assets/characters/shenshen/videos/manifest.json` + `packs-index.json` 是动作清单。
- T1.2 已把 106 个 webm 扁平复制到 `$DSH_HOME/dsh-pet/pet/shenshen-animation/`。**无需再导入**。

### 3. `aboutme-pets`（webm 的精灵图仓库）
- `pets/{dsh,dsh1,gpt,claude,gemini}/spritesheet/`：每个动作 = `<名>.webp`（透明精灵图）+ `<名>.json`（帧元数据 FrameWidth/FrameHeight/Columns/FrameCount/SampleFps）。
- `spritesheet_to_video_pet.py` 可把精灵图逆回透明 webm；`convert_video_pet_spritesheet.py` 反向切图。
- 价值：**额外的 webm 动作池来源**（gpt/claude 批次含 193/166 个非内置动作），可用脚本逆回后补进 `pet/<id>-animation/`。

### 4. `Coopanion` 与 `dsh-coopanion`（layered png 参考：whale body）
- `web/whale/{tex,feat,thumbs,outfits/*,schemes/*/{tex,feat}}`：分层 PNG（纹理层 / 特征层 / 换装 / 各服务商配色）。
- `web/kit/body.js`（`body-host.js` 加载）是 2D body 装配渲染器。
- 价值：分层 PNG「本体 + 特征 + 换装」的组织方式，可作为 layered 渲染器的皮肤结构参考。

### 5. `dsh-anime25d-pets`（layered 参考：PSD 2.5D rig）
- `assets/models/sample.psd`（分层 PSD 模型）+ `assets/lib/{rigger.js,genericparts.js,eye_close.psd,mouth_close.psd}` + `assets/vendor/ag-psd.min.js`。
- 依赖 [Anime2.5DRig](https://github.com/852wa/Anime2.5DRig)（WebGL 自动装配 + 发丝物理 + 表情）。
- 价值：**分层 PSD → WebGL 画布**的完整实现路径，可作为 layered 渲染器的进阶参考（PSD 解析器 ag-psd + 装配参数）。

### 6. `surfcore`（本体非皮肤，皮肤在外部目录）
- 仓库本体是 QQ/bilibili 直播机器人框架，`assets/deepseek娘.png` 只是头像，`roles/*.md` 是人设文案。
- 真正的分层皮肤在 **`D:\AI\FishChi\body\skins\`**（见下）。

### 7. `dsh-bili-whale`（不适用）
- bilibili 直播弹幕机器人（auth/动态/直播/私信），无桌宠渲染素材。

## 四、导入方式

```bash
# 预演：列出将复制/生成的文件
node dsh-pet/scripts/stage-reference-skins.mjs --dry-run

# 实际导入 layered（surfcore 5 套，默认）
node dsh-pet/scripts/stage-reference-skins.mjs

# 导入时就让某一套上屏（默认 none：导入不等于上屏）
node dsh-pet/scripts/stage-reference-skins.mjs --display=web

# 同时导入 live2d 源工程（约 694MB，仅复制 PNG 层 + PSD，不编译）
node dsh-pet/scripts/stage-reference-skins.mjs --with-live2d
```

脚本产物落在 `$DSH_HOME/dsh-pet/pet/`：

```
pet/<id>-config.json     文件宠物配置（renderer: layered / live2d）
pet/<id>-skin/           皮肤资产（layered: manifest.json + art/*.png；live2d: 分层 PNG + PSD）
```

导入项默认 `display: "none"`：它们是**候选皮肤**，导入本身不上屏。导入后重启 fish 实例，
`/config` 会出现对应的 `feiyu-*` / `deepseek-live2d` 条目；要让某一套显示，就在设置页
「桌宠配置」里把该种类的显示方式改成 web / desktop（或导入时给 `--display`）。
网页端与桌面端各自同时只渲染一只宠物，多个条目都标成 web 时按「内置条目优先、其余按配置顺序」取第一只，其余只打一条告警。

## 五、给 T2.3 / T2.4 的落点

- **T2.3 layered**：以 `feiyu-*/manifest.json` 为契约，移植 skin 扫描 + canvas 分层合成 + 锚点变换 +
  命中区 + 口型/眨眼/尾巴动作（参考 `Coopanion/web/kit/body.js` 与 `dsh-anime25d-pets` 的 rigger）。
- **T2.4 live2d**：以 `live2d_build/*` 的分层 PNG 为皮肤（无 .moc3 时退化为 layered 预览），
  接 `pixi-live2d-display` + Cubism Core 后按 `.model3.json` 加载。
